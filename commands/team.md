Task: $ARGUMENTS

Pick the smallest set of this plugin's agents that covers the task, from architect, code-reviewer, test-engineer, debugger, content-strategist, seo-specialist, copywriter, social-media-manager, prospect-researcher, outreach-writer, deal-coach and proposal-writer.

1. Say which agents you chose and what each one will do, in one line each.
2. Run independent agents in parallel. Run dependent ones in order, passing each one's output to the next (for example prospect-researcher before outreach-writer, architect before test-engineer).
3. Combine the results into one answer and flag anything the agents disagreed on.

If the task needs six or more independent pieces of work, suggest /agent-army instead.
